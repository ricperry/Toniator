Toniator 0.3.0 adds **video import, animated Pattern settings, and video export**
to the native Linux halftone-art workflow. Open moving artwork, design its Start
and End states with the normal editing controls, and render a PNG sequence or
a finished video. Both packages include the graphical application, CLI, and
their own software media tools.

## New video and animation features

- Open video, animated images, or an explicitly ordered image sequence. Still
  images can also supply the artwork for animated Patterns.
- Switch between **Start frame** and **End frame** below the canvas. Animate
  20 continuous property types with interpolation, including Pattern size,
  rotation, placement, sampling response, and opacity where supported.
- Assign colors using the selected frame's color picker or HEX entry, with
  alpha and color/hue animation for RGB and all CMYK channels.
- Export **lossless FFV1/Matroska video**, preserving rendered RGB and alpha,
  or a numbered **PNG sequence**. Optional **AV1/WebM** produces a smaller,
  lossy sharing file with an explicit opaque background. The CLI also supports
  SVG sequences and exact frame/time selection.
- Choose an output folder or retain a personal default. Video encoding uses
  private temporary PNG frames, with cancellation and recovery options.
- Save source media and editable animation settings in portable `.toniator`
  projects. Start/End editing preserves independent channel settings and resets
  only affected End settings when a Pattern changes.

## Other improvements

- Source-free document Presets: **Save preset** writes `.toniator-preset`;
  **Load preset...** also accepts a valid current `.toniator` project and keeps
  the destination artwork and timing.
- More representative overall preview progress and more frequent updates.
- Corrected Preset-menu availability after Pattern edits and wizard dismissal.
- Separate welcome window, scrollable Recent Files, and bounded warning text
  that fixes excessive main-window height. The settings divider now resizes
  normally, and frame/comparison controls share the canvas toolbar.
- Opening a second file forwards it through the running application's normal
  unsaved-document decision.

## Install

Choose one x86_64 package from this release. For AppImage:

```bash
chmod +x Toniator-0.3.0-x86_64.AppImage
./Toniator-0.3.0-x86_64.AppImage
```

The AppImage requires glibc 2.39 or newer. If FUSE is unavailable, prefix the
launch command with `APPIMAGE_EXTRACT_AND_RUN=1`.

For Flatpak:

```bash
flatpak install --user ./Toniator-0.3.0-x86_64.flatpak
flatpak run com.sbdd.Toniator
```

The GNOME 50 runtime may be downloaded separately. This bundle is not a Flathub
listing or an automatic-update feed. Flatpak keeps its own settings and personal
Pattern library; installing it does not copy the native/AppImage library.

Download `SHA256SUMS` beside the packages and verify with:

```bash
sha256sum --ignore-missing -c SHA256SUMS
```

`build-info.json` records exact package checksums and source/runtime provenance.
The larger packages include FFmpeg/FFprobe, software codecs, and corresponding
source archives, so a separate host FFmpeg installation is unnecessary.

## Scope and compatibility

- This is a pre-release. Current development project and Preset formats are
  required; obsolete formats are rejected rather than automatically migrated.
- Outputs are **silent**: source audio is not exported. Preview selection is
  Start/End only; playback and timeline scrubbing are not included.
- Variable-frame-rate sources are sampled at the selected project frame rate;
  frames may repeat or be skipped. Rendering complex artwork can be expensive.
- These packages contain the accepted implementation at `0f86251`, recorded by
  acceptance checkpoint `681959b`. The subsequent separate image/video export
  menu change is not included; use **Export** to open the animation sheet and
  **Export current frame…** there for a single PNG/SVG.

Verified with focused tests, native PNG/SVG inspection, exact ten-frame RGBA
FFV1 checks, alpha and AV1 witnesses, private Wayland UI tests, and isolated
Flatpak portal checks. See the [implementation record](https://github.com/ricperry/Toniator/blob/v0.3.0/docs/STAGE_22_23_IMPLEMENTATION.md)
and [known issues](https://github.com/ricperry/Toniator/blob/v0.3.0/ISSUES.md).
