Toniator turns still images into halftone artwork made from dots, lines, curves,
and shapes, with editable SVG and PNG output. This native Linux pre-release
includes the GTK4 application and headless CLI.

## Highlights

- RGB, CMYK, and source-color workflows with independent channel Patterns.
- Seventeen built-in Patterns, a guided Pattern Wizard, and personal Pattern
  save/update/copy/rename/trash management.
- Authored guides, shapes, and curved motifs; precise numeric Pattern size.
- Portable `.toniator` projects containing source artwork and editable settings.
- Startup screen, Recent Files, document Undo/Redo, and save prompts on Close/Exit.
- System light/dark preference support and the author's new application icon.
- First AppImage and Flatpak packages using `com.sbdd.Toniator`.

## Install

Choose one x86_64 package. For AppImage:

```bash
chmod +x Toniator-0.2.0-x86_64.AppImage
./Toniator-0.2.0-x86_64.AppImage
```

The AppImage requires glibc 2.39+. If FUSE is unavailable, prefix the launch
command with `APPIMAGE_EXTRACT_AND_RUN=1`.

For Flatpak:

```bash
flatpak install --user ./Toniator-0.2.0-x86_64.flatpak
flatpak run com.sbdd.Toniator
```

The shared GNOME 50 runtime may be downloaded separately. The Flatpak has its
own settings, recent history, and personal Pattern library under
`~/.var/app/com.sbdd.Toniator/`; native/AppImage Patterns are not copied during
installation. This bundle is not a Flathub listing or an automatic-update feed.

Download `SHA256SUMS` and run `sha256sum --ignore-missing -c SHA256SUMS` next to
the downloaded packages. `build-info.json` records their source, runtime, icon,
and checksum provenance. Build instructions and output examples are in the
[README](https://github.com/ricperry/Toniator/blob/v0.2.0/README.md).

## Verification and known limitations

Tested on Fedora 44 with isolated Wayland startup, open/save/reopen, Close/Exit,
and theme checks. Both package formats rendered the project's intrinsic PNG/SVG
fixtures with matching results; packaged icons and checksums were verified.
These automated checks do not constitute exhaustive GNOME/Mutter or native
file-portal acceptance.

This is a development release. Obsolete project formats are rejected rather
than migrated automatically. Very fine Patterns and first-use personal
thumbnails can be slow; an intermittent RGB-to-CMYK crash report remains open;
a second launch does not forward a file to an already-running window.
See [known issues](https://github.com/ricperry/Toniator/blob/v0.2.0/ISSUES.md).
Document-level Presets remain planned; the current personal library stores Patterns.
