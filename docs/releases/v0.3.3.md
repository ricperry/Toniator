# Toniator 0.3.3 — Sharper previews and scalable exports

Toniator 0.3.3 is a prerelease for Linux x86_64. It includes the AppImage and
Flatpak packages. The currently published portable Windows development build
remains a separate 0.3.2 build; this release does not include a Windows 0.3.3
package or claim that its new features were verified on Windows.

## What changed

- Zoomed and panned previews rerasterize the visible viewport at its physical
  display scale, keeping artwork sharp while retaining shared Preview/Source
  zoom and pan.
- PNG export offers **1x, 2x, 4x, 8x, and Custom** output sizes. The 1x default
  uses the document canvas, independent of preview zoom, and the dialog shows
  the selected pixel dimensions.
- Video export offers **0.5x, 1x, 2x, 4x, 8x, and Custom** sizes based on the
  document canvas. Invalid or over-limit sizes disable export with an inline
  explanation. The native 1x route and existing codec choices remain available.
- The Pattern Wizard guides edits through **Family**, **Family options**,
  **Drawing**, and **Review**. Its controls follow the selected Pattern's
  capabilities; applying the reviewed result is one undoable document change,
  while saving a reusable Pattern remains separate.
- **Feature size** now adjusts both mark fineness and site spacing or density
  across supported scatter and parametric families. Saved Pattern recipes stay
  unchanged. Scatter offers Random, Poisson disk, Jittered cells, and Clustered,
  with optional ordinary or artwork-weighted Lloyd relaxation.
- Wizard previews show repeated guide and curve paths and point sites as
  non-exported overlays. Setting descriptions and About/help entry points make
  the Pattern workflow easier to understand.
- The source includes native MSVC Windows build instructions and the Windows
  filesystem support. Build instructions and the separately versioned Windows
  development download are described in the
  [README](https://github.com/ricperry/Toniator/blob/v0.3.3/README.md).

## Known limits

Fine full-size Review can still take a long time for dense Poisson Patterns
with weighted Lloyd relaxation. Preview responsiveness improvements do not
resolve that separate performance issue. See
[known issues](https://github.com/ricperry/Toniator/blob/v0.3.3/ISSUES.md).
The broader scatter-variety report also remains open.

The available Windows development ZIP contains 0.3.2 debug binaries. Windows
sequence-video UI automation remains incomplete, and new 0.3.3 features have
not been validated on Windows. See the [native Windows build guide](https://github.com/ricperry/Toniator/blob/v0.3.3/docs/windows-build.md)
for current coverage and limits.
