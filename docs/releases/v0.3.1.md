# Toniator 0.3.1 — Reliable editing and source response

This development release improves RGB/CMYK editing, source interpretation, and
video export in the native Linux application.

## Highlights

- **Independent source controls:** Advanced Settings has separate Fill response
  and Source weighting groups, each with its own source-channel mapping and tonal
  adjustments. Patterns remain reusable recipes without embedded source mappings.
- **More tonal control:** black/white levels, gamma, centered contrast, and a
  cutoff for suppressing small responses. Weighting also has its own strength
  and response curve. Eligible numeric settings animate through normal Start/End
  editing.
- **Reliable ALL editing:** changed compatible settings apply to every channel,
  including existing overrides, while untouched settings are preserved.
- **Consistent transforms:** Rotation and X/Y offsets work with artwork-weighted
  patterns. Weighting is recalculated at the transformed positions; neutral
  transforms restore source alignment.
- **Clearer video export:** separate Export image and Export video actions, plus
  explicit frame rate and duration with a derived frame count. Video sources
  initialize timing from their source; still artwork can have a defined animation
  duration. PNG sequences, lossless FFV1/Matroska, and optional AV1/WebM remain
  available.

## Editing fixes

- Pattern Wizard Apply requires a current successful construction check, with
  guidance for invalid Spiral settings.
- Scatter styles retain their parameters when switching between styles;
  unconstrained sampling is labeled Random.
- Advanced source edits preserve expanded channels and scroll position. One
  Reset to defaults button resets all Advanced settings for ALL or the selected
  channel, including paint.
- Switching color models uses the document's baseline Pattern rather than a
  single channel's Pattern override.
- Numeric edits defer GTK control replacement until the input callback finishes,
  addressing the reported CMYK rotation/offset editing problem.
- Selecting a video-export directory no longer triggers the reported borrow panic.
- Feature size, Coverage, editable minimum fill, and X/Y offsets have clearer
  placement in the main inspector.

## Downloads and scope

Choose the x86_64 AppImage or Flatpak bundle. Both contain optimized release
builds of the GUI, CLI, and private open-source media tools. Checksums and build
provenance accompany the packages. Flatpak requires the GNOME 50 runtime;
the AppImage requires glibc 2.39 or newer.

Toniator remains pre-release. Current formats are document schema 10,
document-Preset format 3, and Pattern format 5; superseded development formats
are rejected without automatic migration. Keep original artwork and older
project files when evaluating this release.

Audio, playback, timeline scrubbing, hardware acceleration, and a curves graph
editor are outside this release. Verification includes native PNG/SVG outputs,
focused behavioral tests, and private GTK/Wayland checks; broader distribution
and desktop integration coverage is not claimed.
