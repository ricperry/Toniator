# Toniator 0.4.2 — Patterns, calibration and large PNG export

2026-10-13

Toniator 0.4.2 is a Linux x86_64 prerelease for AppImage and Flatpak, including
the graphical app and headless CLI. This checkpoint brings together the verified
TON-018 implementation milestones. TON-018 remains in progress pending user
review and acceptance; this release does not claim stable-release, physical-print
or comprehensive desktop acceptance.

## What changes

- Fourteen built-in Document Presets provide complete starting configurations.
  They use the existing replacement confirmation and apply as one undoable
  change. Saving a personal copy remains separate.
- Saved calibration is reused across artwork, Feature size, whole-Pattern and
  Shape rotation, seed variation, response edits and eligible continuous animated
  frames. Named-channel Recalibrate updates only that channel; All updates every
  channel and its baseline. End shows the rotation warning, including full turns.
  Structural preparation still produces a fresh calibration before publication.
- Calibration repairs preserve convex inset collapse, fit the aligned Hex Grid
  case within the 144-knot bound, and keep authored open-guide shape stable across
  Feature sizes. Static Wizard Review/Apply and history publication recover
  correctly after calibration completes.
- Native raster Boolean processing uses checked bounded retries for the fine
  Two-Guide Maze case. All 64 current source/family/default-and-fine cases render;
  all 63 available prior outputs retain exactly identical decoded RGBA. This is
  bounded regression evidence, not universal geometry correctness.
- SVG export joins eligible opaque runs within each channel and intersects final
  fills with the canvas while retaining cubic curves, circle arcs, winding, holes
  and translucent paint order. The checked guide examples shrink by 11.07% and
  26.02%. Exactly point-collapsed authored contours no longer reject otherwise
  valid output; positive tiny-geometry precision guards remain.
- Ordinary still PNG and prepared PNG with all three correction widths zero
  stream in row bands and publish atomically. Exact requested dimensions and
  print-fit DPI are retained. Full-size preview and advisory Review limits no
  longer block otherwise valid large export. Invalid current fields cannot
  export an older valid selection, and cancellation preserves the prior file
  before publication. A postpublication folder-sync error reports that the PNG
  was written.

Actual CLI and GTK exports at 16384×9312 fully decode. The prepared GTK file
retains 300 DPI metadata; zero-cleanup preparation produces binary alpha before
applying the selected backing. Both immutable sample artworks have exact
streaming/full-raster parity checks. No PNG route substitutes SVG rasterization.

## Formats and packages

Current formats remain project schema 17 in media container 2, Document Preset
format 3 with configuration schema 16, and standalone Pattern format 8.
Supported older source-free Document Presets convert deterministically while
preserving original bytes. Ordinary projects remain current-only; obsolete
formats and affected obsolete calibration companions require explicit action.

Linux packages use application ID `io.github.ricperry.Toniator` and include the
GUI and CLI. The separate Windows development package remains version 0.3.2;
there is no 0.4.2 Windows package. Checksums and source/runtime provenance belong
in the release's `SHA256SUMS` and `build-info.json` attachments.

## Known limits

Fresh structural calibration can take about two minutes in the measured dense
case. Dense geometry still uses substantial memory: the tested large photo's
AA-on headless export peaks around 2 GiB. Bounded row-band pixel buffers do not
bound the entire process. Some upstream geometry phases remain synchronous and
have documented cancellation gaps.

Nonzero global print corrections retain a 32,000,000-pixel limit. Set Remove
isolated below, Minimum feature width and Minimum gap width to zero to export a
larger prepared PNG, or choose a smaller print area/DPI. Full previews, advisory
Review, video and sequences retain their separate existing limits; video and
sequence streaming are unchanged. Preparation does not certify print safety.

SVG consumers can differ from native PNG in blending, antialiasing and faint
coverage; two inherited Inkscape tiny-alpha spikes remain. SVG source text also
depends on installed fonts. SVG-derived PNG is not selected as the native route.

Focused automated private-Sway semantic and visual checks do not establish
human, GNOME Shell/Mutter, portal or assistive-technology acceptance. Physical
keyboard delivery remains unverified in the inactive private headless seat.
Broad distribution compatibility is not established. See [known issues](../../ISSUES.md)
and the [packaging guide](../../packaging/README.md).
