# Toniator 0.3.2 — New application identity and icon

This prerelease updates Toniator's desktop identity and icon and cleans up the
public source repository. It retains the halftone, Pattern, Preset, and animation
workflows from 0.3.1.

## What changed

- The application ID is now `io.github.ricperry.Toniator`, matching the
  GitHub repository owner. GTK, Flatpak, desktop metadata, and icon names agree.
- The application and package icons use the new RGB halftone design.
- The README and installation instructions use the current release and icon.
- The main source tree now focuses on the current application, specifications,
  examples, tests, and user/build documentation. Legacy implementations,
  development plans, and design experiments are no longer tracked on main.
  Historical commits and older releases remain available.
- Package binaries are release attachments, rather than files in the source tree.

## Flatpak users: the identifier changed

The previous ID was `com.sbdd.Toniator`. The new Flatpak installs as a
**separate application**, not an in-place update to the old ID.

```sh
flatpak install --user ./Toniator-0.3.2-x86_64.flatpak
flatpak run io.github.ricperry.Toniator
```

The new private data directory is `~/.var/app/io.github.ricperry.Toniator/`.
Existing settings and personal Patterns under `~/.var/app/com.sbdd.Toniator/`
are not automatically migrated or deleted. Keep the old installation until
you have recovered the settings or personal Patterns you need. Project files
remain in their existing locations and can be opened if their format is supported.
Native and AppImage personal data paths are unchanged.

## Downloads

Choose one x86_64 package:

- **AppImage:** make executable and run. Requires glibc 2.39 or newer.
  If FUSE mounting is unavailable, set `APPIMAGE_EXTRACT_AND_RUN=1`.
- **Flatpak:** install the bundle; GNOME Platform 50 may be downloaded.
  This is a GitHub-distributed bundle, not a Flathub listing.

Both contain the GUI, CLI, and private software media tools. The Flatpak has
no blanket home or network access. Download `SHA256SUMS` with the package
and verify using `sha256sum --ignore-missing -c SHA256SUMS`.
`build-info.json` records build provenance and artifact hashes.

This remains a prerelease. Broader distribution compatibility and exhaustive
GNOME/Mutter/portal behavior are not established. Known issues are listed in
the repository's ISSUES.md. Older document schemas remain unsupported; this
release does not add project-format migration.
