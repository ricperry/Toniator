# Toniator 0.4.1 — Calibration and response checkpoint

Toniator 0.4.1 is a Linux x86_64 prerelease distributed as an AppImage and
Flatpak. This checkpoint includes the accepted TON-013 through TON-017 fixes
and ongoing TON-018 saved calibration and response work. TON-018 remains in
progress; this release does not claim complete GTK workflow or Pattern-family
coverage.

## Checkpoint

- Guide-cell construction and curve outlines preserve missing shapes and faint
  detail more reliably. Raster antialiasing measures covered pixel area, and
  RGB preview backing preserves very faint shadow values before byte conversion.
- Built-in Patterns apply directly, Advanced Settings has a direct entry, and
  the last All-channel Appearance settings survive color-model switches.
- A finished structural Pattern revision stores a calibration reused across
  artwork, Feature size, whole-Pattern rotation, seed variation, and response
  edits. Structural preparation replaces it; Advanced provides manual
  Recalibrate.
- Uniform Mark sizing targets 99.9% statistical geometric coverage. Variable
  sizing retains artwork-weighted point density. Strict Visible Mark Margin
  requires Variable sizing.
- Current formats are project schema 17 in media container 2, Document Preset
  format 3 with configuration schema 16, and standalone Pattern format 8.
  Supported older Document Presets convert deterministically while preserving
  their original bytes; ordinary projects remain current-only.
- The saved calibration and rendering fixes have focused native-output evidence
  for both immutable sample inputs. The exact rotated RGB dots photo at Feature
  0.25 rendered in 11.12 seconds with 1.33 GiB peak memory on the tested system.

## Known limits

Opaque SVG joining is approved but not implemented. Four of fifteen isolated
personal Document Preset conversion candidates fail across UniformOffset,
HexGridDotsAlignedRGB, and SkinnyCurve bindings; the original files remain
untouched. Broad GTK workflow and Pattern-family coverage is incomplete.
Some animated structural edits can report missing calibration; their saved
calibration behavior remains unresolved.

PNG output is limited to 67,108,864 pixels; tiling is not implemented. Automated
private-Sway checks do not establish human review or GNOME Shell/Mutter
acceptance. See [known issues](../../ISSUES.md).
