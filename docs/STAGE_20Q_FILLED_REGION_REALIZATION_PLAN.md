## Contract

Stage 20Q realizes fill-only `Full`, `Scale`, and `ConstantGap` treatments for accepted ordinary Voronoi and Guide Face regions. It adds reference-point and area-average sampling, sampled per-region paint, reusable treated-region geometry, bounded cache-aware evaluation, and native PNG/SVG evidence. The current one-output authoring gate, schema-v5/preset-v3 version numbers, accepted untreated region identities, centered guide origin, and final-canvas-clip-only rule remain intact. There are no flags, GTK controls, frontend-owned effective model, site filters, outlines, wall complements, fallback marks, renderer topology repair, compatibility adapters, protected-spec changes, or four-guide Guide Face behavior.

`RegionGeometryResponse` is `Full { sampling }`, `Scale { sampling, minimum_scale, maximum_scale }`, or `ConstantGap { sampling, minimum_gap, maximum_gap }`, where sampling is `RegionSamplingStrategy::{ReferencePoint, AreaAverage}`. The mapped scalar linearly interpolates the typed endpoints after existing inversion/gain/bias. Scale is finite, ordered, nonnegative and unclamped above; gap is finite, ordered, signed canvas units and unclamped. `RegionGeometryResponseDelta` has treatment-specific optional endpoints; Full rejects deltas and Scale/gap reject each other's unit. Effective arithmetic is additive, finite, unclamped, output-ID keyed, and domain-owned.

`RegionGeometryFieldEdit` and existing effective-response helpers preserve an absent companion delta for one-field edits and retain output-keyed reset. Atomic `PatternOutputSettingsEdit::SetRegionResponse` and selected/shared bundle edits carry an exact stale `PatternDefinitionBundle` base. Selected edits clone/remap when shared and retain compatible deltas; treatment changes prune incompatible deltas while sampling/numeric changes retain them. Shared edits retain IDs and affect linked channels in document order. History restores exact old bundle and deltas. Treatment/sampling invalidates `Family`; numeric base/effective response invalidates `Realization`; selected copy-on-edit is `Family`; paint/opacity retain existing invalidation.

Descriptors expose treatment/sampling targets and Scale/gap endpoint targets. Scale lower bound is zero and upper is unbounded; gaps accept finite values; Full exposes no numeric descriptor. Capability projection reports region source, treatments, sampling strategies, sampled-paint support and applicable base/effective response in output order, never regions or samples. Document v5/preset v3 persist tagged source/treatment/sampling, keyed numeric base/deltas only. Current fixtures port to explicit Full+ReferencePoint; missing/malformed treatments and v4/v2-or-older formats are rejected. Never persist effective values, references, samples, treated regions, diagnostics, limits, caches, or scheduler state.

## Geometry, sampling, pipeline and rendering

Geometry owns references keyed one-to-one by untreated `CanonicalRegionId`: ordinary Voronoi uses the normalized shared duplicate-site coordinate and Guide Faces use analytic area centroids. References do not change accepted untreated fingerprints. Full exact-replays. Scale affinely transforms all line/cubic/control points around the reference; zero removes, positive preserves winding, and greater than one may overlap. ConstantGap maps `g` to inward signed `g / 2`; zero is exact no-op, positive insets and negative grows. Reuse accepted offset/intersection primitives then crossing split, interior/winding classification, invalid branch dissolution, positive-ring assembly, canonical ordering and hole removal. Collapse removes; never clamp/fallback. Treated sets may be empty. Split components inherit base identity/reference/sample and have deterministic contiguous ordinals after canonical ordering.

Aggregate canonical limits per treatment request: 1,048,576 source/retained regions, 8,388,608 retained segments, 67,108,864 inspections; reuse offset defaults of depth 48, 262,144 candidates, 65,536 components, 1,048,576 cleanup pairs, 262,144 cusp inspections and `1/64` fitting tolerance. Sampling limits are 33,554,432 source-cell intersections, 8,388,608 flattened segments, depth 48 and `1/64` source-pixel tolerance. ReferencePoint uses existing edge-clamped mapped associated-color sampling. AreaAverage samples complete untreated off-canvas regions, deterministically flattens cubic boundaries in decoded source coordinates, partitions/clips against bilinear cells and exterior clamp bands, integrates scalar/associated RGB/alpha by polygon moments, divides by complete area, and unassociates only positive alpha. Samples drive response and sampled paint; exact-zero alpha suppresses all components for that base. Cancellation remains exactly `evaluation.cancelled`; failure never publishes an empty partial candidate.

Patterns owns one typed region output realizer. Independently cached keys include producer/treatment contracts, output ID, untreated identity, reference bits, typed response/sampling, needed source/mapping identity, sampled-paint mode, limits and coverage. Full+solid replays accepted 20O/20P fingerprints; sampling/treatment fingerprints include ordered bases, references, samples, resulting geometry and sampled paint. Limits stay outside geometry fingerprints but in cache keys. Support adds `max(0, -minimum_gap)/2` for gaps and conservative outward Scale support; finite overflow fails before allocation. Shared family requests take max support and may reuse broader envelopes. Cache hits replay diagnostics; failed/cancelled/stale work publishes nothing.

`GeometryOutput` consumes possibly empty treated regions. Region primitive paints align in canonical region order; strokes reject sampled paint. Raster/SVG combine per-region paint and channel opacity, fill already closed positive rings with nonzero semantics, and only final-clip. They never construct topology. Existing marks/strokes/painter behavior stays unchanged.
